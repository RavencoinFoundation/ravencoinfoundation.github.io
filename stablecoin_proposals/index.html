OpenDAO — USDO

This proposal required $25,000 worth of RVN for the OpenDAO project, to incentivize people to use pRVN as collateral backing USDO — an algorithmically stabilized smart contract on the Binance Smart Chain. It would have created a USDO token backed by pRVN, allowing you to borrow a USDO stablecoin against your RVN.

Required: $50,000 in RVN.
Details: OpenDAO proposal
RVN contribution address*: RJzkp2xcXkEQYXYfZzdBTrvCNxy2GKqjLn

Status: paused — OpenDAO is no longer an option.

Stably — USDS

This proposal required development from Stably to interact with Ravencoin, with the intermediate code released as open source. The USDS token would have been minted on the Ravencoin blockchain and backed 1:1 with USD held at Prime Trust, putting a stablecoin directly on-chain for use in atomic swaps.

Required: $125,000.
Details: Stably proposal (PDF)
RVN contribution address*: RBzm8wmbEcdFxAWAZ2stkxSN615uDgvqCd

Status: paused — Prime Trust closed and Stably is paused for an indeterminate amount of time.
